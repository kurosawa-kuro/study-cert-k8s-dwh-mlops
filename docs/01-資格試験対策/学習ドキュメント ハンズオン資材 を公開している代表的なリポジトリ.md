#### 使い分けのコツ

| 目的                         | オススメリポ                                                 |
| -------------------------- | ------------------------------------------------------ |
| **まず演習で手を動かしたい**           | CKAD: `CKAD-exercises`, CKA: `cka-certification-guide` |
| **公式ドキュメントの “速引き索引” が欲しい** | `cka-preparation-guide`, `cks-preparation-guide`       |
| **試験直前の詰め込み & Tips**       | `tips-for-CKA-CKAD-CKS`                                |
| **セキュリティ領域を深掘り**           | `Kubernetes_Security_Specialist_Study_Guide`           |

> **活用法**
>
> 1. 自分の GitHub アカウントに Fork して VS Code Dev Container／Codespaces で即ラボ開始。
> 2. README の章立てを Notion や Obsidian に取り込み、弱点セクションだけタグ付け。
> 3. 試験 1 週間前は “killer.sh” or “Killercoda” で通し模試 → 解説をリポと突き合わせて復習。

これらをブックマークしておけば、**CKAD → CKA → CKS のステップアップ学習**がスムーズに進むはずです。頑張ってください！
