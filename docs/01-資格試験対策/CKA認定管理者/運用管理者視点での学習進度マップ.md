**運用管理者視点**に焦点を当てて、各認定試験における運用管理能力の発展を整理します。

## 運用管理者視点での学習進度マップ

### **KCNA (エントリーレベル)**
**運用管理知識：** 運用管理の存在認識
**実際の運用能力：** なし
- 「誰かがクラスターを管理している」ことを理解
- **運用管理者としての実務能力：ゼロ**

### **KCSA (セキュリティ基礎)**
**運用管理知識：** セキュリティ運用の責任理解
**実際の運用能力：** 設計・方針策定のみ
- セキュリティ運用ポリシーの必要性理解
- **実装能力：なし（方針設計のみ）**

### **CKAD (開発者視点)**
**運用管理知識：** 限定的な運用知識
**実際の運用能力：** 開発支援レベル
```bash
# 開発者としての運用支援
kubectl get pods --all-namespaces
kubectl describe node  # 読み取りのみ
kubectl top pods       # リソース使用量確認
```
- **運用管理者の依存先** - 本格的な運用はできない
- 開発環境での軽微な運用サポート

### **CKA (運用管理者の核心)**
**運用管理知識：** フル運用管理知識
**実際の運用能力：** 完全な運用管理実装
```bash
# 本格的なクラスター運用
# 1. クラスター生成・管理
kubeadm init --pod-network-cidr=10.244.0.0/16
kubeadm join --token xxx

# 2. ノード運用管理
kubectl drain worker-node-1 --ignore-daemonsets
kubectl cordon worker-node-2
systemctl restart kubelet

# 3. バックアップ・復旧
etcdctl snapshot save /backup/etcd-snapshot.db
etcdctl snapshot restore /backup/etcd-snapshot.db

# 4. アップグレード管理
kubeadm upgrade plan
kubeadm upgrade apply v1.28.0

# 5. 運用監視
kubectl top nodes
kubectl get events --sort-by=.metadata.creationTimestamp
```

**CKAレベルで担う運用責任：**
- **可用性確保** - クラスター稼働維持
- **パフォーマンス管理** - リソース最適化
- **災害復旧** - バックアップ・リストア
- **容量管理** - ノード・ストレージ拡張
- **ユーザー管理** - RBAC設定・権限管理

### **CKS (セキュリティ強化運用)**
**運用管理知識：** CKA + セキュリティ運用
**実際の運用能力：** セキュリティ強化された運用実装
```bash
# セキュリティ強化運用
# 1. セキュリティ監査運用
kube-bench run --targets node,master
falco --config /etc/falco/falco.yaml &

# 2. セキュリティインシデント対応
kubectl get pods --all-namespaces -o wide | grep Suspicious
kubectl logs -f suspicious-pod -c container

# 3. セキュリティポリシー運用
kubectl apply -f network-policies/
kubectl apply -f pod-security-policies/

# 4. 侵入検知・対応
trivy image nginx:latest
kubectl delete pod compromised-pod --force
```

## 運用管理者としての能力発展段階

### **実際の運用責任レベル**
1. **KCNA/KCSA:** 運用責任なし
2. **CKAD:** 開発環境の部分的運用支援
3. **CKA:** **フル運用責任** - 本番環境のクラスター運用
4. **CKS:** **セキュリティ強化運用責任** - 企業レベルの高度運用

### **運用管理者が扱う技術領域**
```bash
# CKAレベルで必須となる運用技術
# インフラ層
systemctl status kubelet
journalctl -u kubelet
netstat -tlnp | grep kube

# クラスター層  
kubectl cluster-info
kubectl get componentstatuses
kubeadm token list

# アプリケーション層
kubectl rollout status deployment/app
kubectl scale deployment app --replicas=5
kubectl set image deployment/app container=image:v2
```

## CKADから運用管理者(CKA)への学習パス

**運用管理者になるために追加で必要な知識：**

1. **システム管理** - Linux、ネットワーク、ストレージ
2. **クラスター構築** - kubeadm、ネットワークプラグイン
3. **運用自動化** - バックアップスクリプト、監視設定
4. **障害対応** - ログ解析、パフォーマンストラブルシューティング
5. **セキュリティ基礎** - 証明書管理、RBAC設定

**CKADの知識は運用管理の基礎として活用できますが、CKAで本格的な「クラスター運用責任者」になるための大幅なスキルアップが必要です。**
