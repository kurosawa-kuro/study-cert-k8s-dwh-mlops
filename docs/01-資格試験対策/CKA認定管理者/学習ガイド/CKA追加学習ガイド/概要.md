# CKA追加学習ガイド

## 概要

このガイドは、**CKAD 試験で 75 点以上を取得できるレベルの受験者**が CKA 試験に向けて追加学習すべき内容をまとめています。CKAD の試験範囲と重複しない技術テーマに焦点を当て、効率的な学習を支援します。

## 対象者

- CKAD 試験で 75 点以上を取得可能な知識・スキルを有する人材
- Pod 操作、ConfigMap/Secret、Volume、Networking、API 操作などの基本的な Kubernetes 運用を理解している
- より高度なクラスタ管理技術を学びたい運用エンジニア・DevOps エンジニア

## 学習ガイド構成

### [01_マルチクラスタ運用](01_マルチクラスタ運用.md)
- kubeconfig の高度な管理とコンテキスト切り替え
- 複数クラスタの統合管理戦略
- 災害復旧（DR）とクラスタ間でのサービス連携

### [02_ネットワークポリシーの詳細設定](02_ネットワークポリシーの詳細設定.md)
- ゼロトラストネットワークの実装
- マルチティアアプリケーションの通信制御
- CNI プラグインごとの高度な機能活用

### [03_Podセキュリティ基準](03_Podセキュリティ基準.md)
- Pod Security Standards（PSS）の完全理解
- OPA/Gatekeeper によるポリシーエンジン活用
- エンタープライズセキュリティの実装

### [04_CRDとOperatorパターン](04_CRDとOperatorパターン.md)
- Custom Resource Definition の高度な設計
- Operator の成熟度モデル（レベル1〜5）
- 既存 Operator の評価と運用

### [05_ストレージクラスとCSIドライバー](05_ストレージクラスとCSIドライバー.md)
- 動的プロビジョニングの最適化
- CSI エコシステムの理解
- Volume Snapshot による データ保護戦略

### [06_GitOpsとテンプレート管理](06_GitOpsとテンプレート管理.md)
- Git を信頼できる唯一の情報源とする運用
- Helm と Kustomize の使い分け
- ArgoCD/Flux による継続的デリバリー

### [07_セキュリティと監査ログ](07_セキュリティと監査ログ.md)
- API サーバー監査ログの設計
- 統合認証（OIDC）とRBAC の高度な活用
- ランタイムセキュリティと脅威検知

## 学習の進め方

### 1. 事前準備
- 各章の「視点の転換」で CKAD からの発展内容を確認
- 「重点学習内容」で新たに学ぶべき技術要素を把握

### 2. 段階的学習
- 各章の「学習目的」を理解してから「学習手順」に進む
- 「演習アイデア」で実践的なスキルを習得
- 「セルフチェック」で理解度を確認

### 3. 試験対策
- 「CKA試験での出題パターン」で頻出問題を把握
- 「CKAD経験者が陥りがちな誤解」で注意点を確認
- 「学習優先順位」に基づいて効率的に時間配分

## 学習優先順位（全体）

| 優先度 | 技術分野 | 理由 |
|--------|----------|------|
| 高 | マルチクラスタ運用 | CKA 試験で頻出、実務で必須 |
| 高 | ネットワークポリシー | セキュリティ強化の基礎 |
| 高 | Pod セキュリティ基準 | 最新の Kubernetes セキュリティ |
| 中 | ストレージクラス・CSI | 永続化データの高度な管理 |
| 中 | RBAC・監査ログ | 運用における重要な基盤 |
| 低 | CRD・Operator | 概念理解で十分 |
| 低 | GitOps | 運用の効率化（試験では軽い扱い） |
