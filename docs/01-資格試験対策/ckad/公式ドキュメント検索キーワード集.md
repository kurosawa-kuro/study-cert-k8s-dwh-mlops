### ワンポイント覚え書き（ペーストして試験メモに）

```bash
# PV/PVC は YAML テンプレを丸ごと貼る
kubectl explain pv.spec --recursive | head -n 20   # 欄速チェック

# ConfigMap / Secret
k create configmap app-cfg --from-literal=MODE=dev -o yaml --dry-run=client | k apply -f -
k create secret generic db --from-literal=PASSWORD=pass -o yaml --dry-run=client > secret.yaml

# CronJob 雛形（60 min ごと）
k create cronjob backup --image=busybox --schedule="*/60 * * * *" \
  -o yaml --dry-run=client > cj.yaml
```

> **コツ**：表にあるパスをブラウザの URL 欄に直接打つと `/docs/…` 以下へ即飛べます。  
> 例）`kubernetes.io/docs/concepts/storage/persistent-volumes/` で PV 全設定が一画面。試験環境は公式サイトが whitelisted なので、検索より速いです。
