### “書き起こし”専用ルーティン（毎朝‐昼‐夜）

|時間帯|所要|**お題**|ゴール|
|---|---|---|---|
|**朝 (ウォームアップ)**|15 min|1. **alias** 10 行2. **Pod** 最小 YAML|指が温まる＋雛形を思い出す|

## 3️⃣ Deployment（昼前半）

生成ワンライナー ➡ 編集 ➡ 適用

```bash
k create deployment web --image=nginx:1.25 --replicas=3 \
  --dry-run=client -o yaml > deploy.yaml
```

編集点

```yaml
spec:
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxSurge: 1
      maxUnavailable: 0
```

⏱ **目標**：`kaf deploy.yaml` まで 5 分

## 4️⃣ PV / PVC （昼後半）

```yaml
# pv.yaml
apiVersion: v1
kind: PersistentVolume
metadata:
  name: pv-demo
spec:
  capacity:
    storage: 1Gi
  accessModes: [ReadWriteOnce]
  hostPath:
    path: /data/pv-demo
---
# pvc.yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: pvc-demo
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: 1Gi
  storageClassName: ""          # ★ 静的 PV と“空文字”でそろえる
```

⏱ **目標**：pv + pvc を 7 分で書き起こし & Bind を `k get pvc` で確認

## 5️⃣ ConfigMap & Secret（夜前半）

```bash
# ワンライナー作成
k create configmap app-cfg --from-literal=MODE=prod --dry-run=client -o yaml > cm.yaml
k create secret generic db-secret --from-literal=PASSWORD=s3cr3t --dry-run=client -o yaml > secret.yaml
```

Pod にマウント

```yaml
envFrom:
  - configMapRef:
      name: app-cfg
env:
  - name: DB_PASSWORD
    valueFrom:
      secretKeyRef:
        name: db-secret
        key: PASSWORD
```

⏱ **目標**：cm + secret + Pod 環境変数注入を 10 分

---

## 6️⃣ CronJob（夜後半）

```yaml
apiVersion: batch/v1
kind: CronJob
metadata:
  name: backup
spec:
  schedule: "*/5 * * * *"
  jobTemplate:
    spec:
      template:
        spec:
          restartPolicy: OnFailure
          containers:
          - name: rsync
            image: alpine
            command: ["sh","-c","echo backup at $(date)"]
```

チェック

```bash
k get cj,job,pod
```

⏱ **目標**：YAML 作成→ Job 実行確認まで 8 分

### 🔔 ヒント：タイムトライアルの型

1. **`create … --dry-run=client -o yaml`** で雛形を落とす
    
2. **VS Code / vim** のスニペットで共通部分を補完
    
3. **`kaf`** → **`kgp` / `kdes`** で即動作確認
    
4. **失敗したら同じ YAML を “赤ペン” 修正して再 `kaf`**
