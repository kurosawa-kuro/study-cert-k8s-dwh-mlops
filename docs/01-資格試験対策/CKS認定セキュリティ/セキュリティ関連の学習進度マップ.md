各認定試験における「基礎知識」→「調査・実装」の関係性を整理します。

## セキュリティ関連の学習進度マップ

### **KCNA (エントリーレベル)**
**基礎知識：** Cloud Nativeエコシステムの全体像
**調査・実装：** 概念レベルの理解のみ
- Kubernetesが何かを知っている程度
- セキュリティは「重要である」ことを理解

### **KCSA (セキュリティ基礎)**
**基礎知識：** セキュリティ原則とベストプラクティス
**調査・実装：** 理論的な設計判断
- 4C Security、Least Privilege、Defense in Depthの理解
- 「どのセキュリティ手法を使うべきか」の判断力
- **実装はしないが、設計思想は理解**

### **CKAD (開発者視点)**
**基礎知識：** KCSAレベルのセキュリティ概念
**調査・実装：** アプリケーション開発観点での実装
```yaml
# Security Context設定
securityContext:
  runAsNonRoot: true
  readOnlyRootFilesystem: true
```
- Pod設計時のセキュリティ考慮
- **開発者が知るべきセキュリティ実装**

### **CKA (運用管理者視点)**  
**基礎知識：** KCSAレベル + クラスター運用知識
**調査・実装：** クラスター全体のセキュリティ運用
```bash
# RBAC設定、証明書管理
kubectl create rolebinding --clusterrole=view --user=dev-user
```
- クラスター管理者としてのセキュリティ設定
- **運用観点でのセキュリティ実装**

### **CKS (セキュリティ専門家)**
**基礎知識：** KCSA + CKA + セキュリティツール知識
**調査・実装：** 高度なセキュリティ実装 + トラブルシューティング
```bash
# Falcoルール作成、イメージスキャン、侵入検知
falco -r custom_rules.yaml
trivy image nginx:latest
```

## CKADから見たCKSへの道筋

**あなたの現在地（CKAD学習者）：**
- Pod Security Context → ✓ 基礎あり
- Secrets管理 → ✓ 基礎あり  
- Network Policy → △ 実装経験が必要

**CKSに向けて追加が必要：**
1. **セキュリティ理論**（KCSA相当の知識）
2. **クラスター管理**（CKA相当の運用知識）  
3. **セキュリティツール**（Falco、OPA、Trivy等）

CKADの知識は確実にCKSの土台になりますが、セキュリティ専門領域とクラスター管理の両方を追加学習する必要があります。
