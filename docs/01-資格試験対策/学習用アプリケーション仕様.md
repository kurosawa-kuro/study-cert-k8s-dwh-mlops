
以下の内容を学習用アプリケーション仕様としてまとめました。これらを Kubernetes 上にデプロイして、各種機能（Service／Ingress、ConfigMap／Secret、Probe、Resource 管理、Autoscaling など）を実際に試してみてください。

---

## 1. public nginx

**目的**：静的コンテンツ配信＋Ingress／Service／ConfigMap／Probe の基本を学ぶ

* **Deployment**

  * `apiVersion: apps/v1`
  * レプリカ数：2
  * `spec.template.metadata.labels.app: nginx-public`
  * `spec.template.spec.containers[0]`

    * image: `nginx:latest`
    * ports: containerPort `80`
    * volumeMounts:

      * name: `www-content` → mountPath `/usr/share/nginx/html/index.html`
* **ConfigMap**

  * name: `nginx-index`
  * key `index.html` にカスタム HTML を定義
* **Volume**

  * name: `www-content`
  * configMap: `nginx-index`
* **LivenessProbe**

  * httpGet: path `/`, port `80`
  * initialDelaySeconds: 15, periodSeconds: 20, timeoutSeconds: 5
* **ReadinessProbe**

  * httpGet: path `/`, port `80`
  * initialDelaySeconds: 5, periodSeconds: 10, timeoutSeconds: 2
* **Service**

  * type: `ClusterIP`
  * port: 80 → targetPort 80
* **Ingress**

  * host: `nginx.example.com`
  * path: `/` → Service nginx-public:80

## 2. public busybox

**目的**：最小限コンテナで HTTP サーバを立てる→Probe／Resource 管理を学ぶ

* **Deployment**

  * レプリカ数：1
  * labels.app: `busybox-http`
  * containers\[0]

    * image: `busybox:latest`
    * command:

      ```yaml
      ["sh","-c",
       "echo '<h1>Hello from BusyBox!</h1>' > /var/www/htdocs/index.html &&
        httpd -f -p 8080 -h /var/www/htdocs"
      ]
      ```
    * ports: containerPort `8080`
    * resources:

      * requests: cpu `50m`, memory `64Mi`
      * limits:   cpu `100m`, memory `128Mi`
* **LivenessProbe**

  * httpGet: path `/`, port `8080`
  * initialDelaySeconds: 10, periodSeconds: 15, timeoutSeconds: 3
* **ReadinessProbe**

  * httpGet: path `/`, port `8080`
  * initialDelaySeconds: 2,  periodSeconds: 5,  timeoutSeconds: 1
* **Service**

  * type: `NodePort`
  * port: 80 → targetPort 8080
  * nodePort: 30080

## 3. 自作 Node.js Express アプリ

**目的**：アプリ開発者視点（CKAD）＋運用視点（CKA, CKS）をまとめて学ぶ

### アプリケーション要件

* **言語／フレームワーク**

  * Node.js 18.x, Express 4.x
* **エンドポイント**

  * `GET  /` → `Hello, World!`
  * `GET  /healthz` → `{ status: 'ok' }`
  * `GET  /readyz` → `{ status: 'ready' }`
  * `GET  /config` → 環境変数（ConfigMap 経由）を返却
* **ConfigMap／Secret**

  * ConfigMap `express-config`:

    * `APP_GREETING`: `"Hello from Express!"`
  * Secret `express-secret`:

    * `API_KEY`: `<任意の文字列>`
* **Dockerfile**

  ```dockerfile
  FROM node:18-alpine
  WORKDIR /app
  COPY package*.json ./
  RUN npm ci --only=production
  COPY . .
  EXPOSE 3000
  CMD ["node","index.js"]
  ```
* **Kubernetes リソース**

  * **Deployment**

    * レプリカ数：2
    * containers\[0]:

      * image: `your-registry/express-app:latest`
      * envFrom: ConfigMap `express-config`, Secret `express-secret`
      * ports: containerPort `3000`
      * resources:

        * requests: cpu `200m`, memory `256Mi`
        * limits:   cpu `500m`, memory `512Mi`
      * **LivenessProbe**

        * httpGet: path `/healthz`, port `3000`
        * initialDelaySeconds: 30, periodSeconds: 20, timeoutSeconds: 5
      * **ReadinessProbe**

        * httpGet: path `/readyz`, port `3000`
        * initialDelaySeconds: 5,  periodSeconds: 10, timeoutSeconds: 2
  * **Service**

    * type: `LoadBalancer`
    * port: `80` → targetPort `3000`
  * **Ingress**

    * host: `express.example.com`
    * path `/` → Service express-app:80
    * TLS：利用可能であれば ingressTLS 設定
  * **HorizontalPodAutoscaler**

    * minReplicas: 1, maxReplicas: 5
    * targetCPUUtilizationPercentage: 50

---

### 運用／セキュリティ要望

* **ロギング**：標準出力へ JSON 形式で出力
* **監視**：Prometheus 用メトリクスエンドポイント（`/metrics`）を追加検討
* **セキュリティ（CKS 演習）**

  * PodSecurityContext／SecurityContext の適用
  * NetworkPolicy で外部アクセス制限
  * CI パイプラインに Trivy スキャンを組み込み
  * Secret 暗号化（KMS/Vault）

---

### 学習時の進め方

1. **ローカル (kind/minikube)** で manifest を適用し、Pod → Service → Ingress まで確認
2. **AWS EKS** に同じ manifest を適用し、外部公開＋LB/Ingress 周りを検証
3. Probe（死活監視）のログ・再起動挙動を `kubectl describe pod` で追う
4. リソース不足（limits）や HPA が動く状態を再現し、Pod 数の増減を確認
5. セキュリティ演習として NetworkPolicy や PodSecurityPolicy → AdmissionWebhook を試す

この仕様をベースに「手を動かして学ぶ」ことで、CKAD／CKA／CKS 相当の実務スキルが自然と身につきます。何か追加のご要望や細かい設定例が必要でしたら、お知らせください！
