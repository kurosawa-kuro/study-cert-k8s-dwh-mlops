# Supply Chain & Image Security 基礎 — SBOM・署名・脆弱性スキャン

> **対象:** CKAD 85 %・Killer.sh 70 % のスキルを持つエンジニアが **KCSA 試験対策** として習得すべき “サプライチェーン & イメージセキュリティ” の必須トピック。
> **範囲:** SBOM / 署名 (cosign) / 脆弱性スキャン (Trivy) / in‑toto Attestation
> **キーワード:** syft・cosign・Trivy・in‑toto・`cosign sign && cosign verify`

| 領域          | ベストプラクティス                                                                                         |
| ----------- | ------------------------------------------------------------------------------------------------- |

## 3. Hands‑on ラボ（30 分）

> **前提:** Docker / podman と cosign & trivy & syft CLI がローカルにインストール済み。テスト用に `docker.io/library/nginx:1.27` を利用。

### 3.1 SBOM 生成 & アテステーション

```bash
# 1) SBOM を CycloneDX で出力
syft docker.io/library/nginx:1.27 -o cyclonedx-json > sbom.json

# 2) cosign keypair 作成 (初回のみ)
cosign generate-key-pair k8s

# 3) SBOM を in‑toto attestation として署名・添付
cosign attest --predicate sbom.json --type cyclonedx \
  --key k8s.key docker.io/library/nginx:1.27
```

### 3.2 イメージ署名 & 検証

```bash
# 1) イメージをローカルでタグ付け (例として ghcr.io/<user>/demo:1.0 へ)
docker tag nginx:1.27 ghcr.io/yourname/demo:1.0
docker push ghcr.io/yourname/demo:1.0

# 2) 署名
cosign sign --key k8s.key ghcr.io/yourname/demo:1.0

# 3) 検証 (公開鍵 k8s.pub を使用)
COSIGN_EXPERIMENTAL=1 cosign verify \
  --key k8s.pub ghcr.io/yourname/demo:1.0
```

### 3.3 脆弱性スキャン (Trivy)

```bash
# 1) イメージレイヤ脆弱性チェック
trivy image ghcr.io/yourname/demo:1.0

# 2) SBOM モード + Misconfig + Secret もまとめて
trivy image --scanners vuln,config,secret --sbom-type cyclonedx ghcr.io/yourname/demo:1.0
```

### 3.4 Admission Controller で Verify 強制 (Kyverno 例)

```bash
cat <<'EOF' | kubectl apply -f -
apiVersion: kyverno.io/v1
kind: ClusterPolicy
metadata:
  name: require-image-signature
spec:
  validationFailureAction: Enforce
  rules:
  - name: verify-signature
    match:
      resources:
        kinds: [Pod]
    verifyImages:
    - image: "ghcr.io/yourname/*"
      key: "k8s.pub"
      attestors:
      - entries:
        - keyless:
            subject: "yourname@example.com"
            issuer: "https://token.actions.githubusercontent.com"
EOF
```
