# 4 C’s Security Model — A4 クイックリファレンス

> **対象:** CKAD 85 %・Killer.sh 70 % 水準から KCSA 学習を始めるプログラマー向け
> **目的:** Cloud → Cluster → Container → Code の 4 層を俯瞰し、境界と責任分担を理解してベストプラクティスを即確認できる 1 枚ペーパー。

---

## 1. 4 層図（A4 レイアウト想定）

```
┌───────────────────────────────────────────────────────────────┐
│                          Cloud (Provider)                    │
│  ── Boundary: CSPインフラ全体 / 物理セキュリティ / IAM root   │
│  Responsibility: クラウド事業者 & 組織 SecOps                 │
└───────────────────────────────────────────────────────────────┘
┌───────────────────────────────────────────────────────────────┐
│                        Cluster (Platform)                    │
│  ── Boundary: Control‑plane / etcd / ネットワーク境界         │
│  Responsibility: プラットフォームチーム / SRE                │
└───────────────────────────────────────────────────────────────┘
┌───────────────────────────────────────────────────────────────┐
│                       Container (Runtime)                    │
│  ── Boundary: イメージ & ランタイム / Namespaces / cgroups   │
│  Responsibility: DevOps / アプリ所有チーム                   │
└───────────────────────────────────────────────────────────────┘
┌───────────────────────────────────────────────────────────────┐
│                           Code (App)                         │
│  ── Boundary: アプリロジック / ライブラリ / Secrets           │
│  Responsibility: 開発チーム                                  │
└───────────────────────────────────────────────────────────────┘
```

---

## 2. ベストプラクティス（各層 1 行まとめ）

| 層             | 1 行ベストプラクティス                                                    |
| ------------- | --------------------------------------------------------------- |
| **Cloud**     | *IAM ロール境界を最小化し、CSPM (Cloud Security Posture Management) を継続監査* |
| **Cluster**   | *RBAC 最小権限 + Audit Policy で操作を常時記録*                             |
| **Container** | *cosign 署名済みイメージを rootless & read‑only で実行*                     |
| **Code**      | *依存ライブラリをピン留めし、SCA / SAST を CI で自動スキャン*                         |

---

## 3. 境界と責任分担メモ

* **Cloud → Cluster**: VPC／Subnet／Firewall は Cloud 層で定義し、クラスター側では NetworkPolicy で補強。
* **Cluster → Container**: API‑server から RBAC で許可された操作のみがコンテナに届く。
* **Container → Code**: コンテナ runtime が制御する領域外でアプリ自身が凡ミス（Secrets 直書き等）しないよう CI で SAST。
