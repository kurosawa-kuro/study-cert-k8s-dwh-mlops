## 3. Hands‑on ラボ（30 分）

### 3.1 Falco インストール (kind + Helm)

```bash
# 0) Helm repo 追加
helm repo add falcosecurity https://falcosecurity.github.io/charts
helm repo update

# 1) DaemonSet として導入 (Falco 0.38 例)
helm install falco falcosecurity/falco \
  --namespace falco --create-namespace \
  --set falco.jsonOutput=true \
  --set falco.logLevel=info

# 2) Pod 起動確認
kubectl -n falco get pods -l app.kubernetes.io/name=falco
```

### 3.2 `/etc/shadow` 読取を検出するテスト

```bash
# 1) テスト Pod 起動し /etc/shadow を読む
kubectl run read-shadow --image=busybox --restart=Never -- \
  sh -c "cat /etc/shadow || true"

# 2) Falco ログ確認 (数秒待機)
kubectl -n falco logs -l app.kubernetes.io/name=falco --tail=50 | \
  grep "shadow" | head
```

> **期待結果:** `Sensitive file opened for reading` イベントとして `/etc/shadow` パスが含まれた Falco アラートが出力される。

### 3.3 カスタムルールを追加 (任意)

```bash
cat <<'EOF' > custom-rules.yaml
- rule: Detect vi usage in container
  desc: Someone used vi inside a container
  condition: container and proc.name = vi
  output: "Container exec detected (vi) user=%user.name container=%container.name (%container.id)"
  priority: Warning
  tags: [container, shell]
EOF

helm upgrade falco falcosecurity/falco -n falco -f custom-rules.yaml --set falco.rulesFile.append=true
```
